# Becomings website

This is a lightweight, one-page website for Becomings. The live website file is:

- `outputs/index.html`

## Local preview

Open `outputs/index.html` in Safari or Chrome, then refresh the page after making changes.

## Publish with Cloudflare Pages

Connect the GitHub repository `Becomings-SG/Becomings` in Cloudflare Pages and use:

- Framework preset: `None`
- Build command: leave blank
- Build output directory: `outputs`

Cloudflare will publish the website from the `outputs` folder and automatically redeploy whenever changes are pushed to GitHub.

## Future updates

1. Update the text, design, or links in `outputs/index.html`.
2. Preview the page locally in a browser.
3. Commit and push the update to GitHub.
4. Cloudflare Pages redeploys automatically.

Do not add passwords, access tokens, private client information, or API keys to this project.
